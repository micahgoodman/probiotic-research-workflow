# Probiotic evidence catalogue

The tier says how much evidence exists. It does not say how good the result was; the verdict does. A program computes both by counting studies. It does not weigh them, so read the number of people too. RULES.md explains every column.

- **Tier B**: 2 or more randomized trials compared the probiotic with a placebo group.
- **Tier C**: exactly one such trial.
- **Tier D**: no such trial, only weaker studies: no placebo group, no random assignment, or a change inside one group with no comparison against placebo.
- Tier A (a review that pools one strain's trials) and tier P (animal and lab studies) are not used.
